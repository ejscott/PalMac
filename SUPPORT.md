# Support

PalMac is an experimental community project.

For bugs and feature requests, use GitHub Issues and include:

- Mac model and macOS version;
- Palworld version and revision shown by PalMac;
- PalMac commit or release version;
- package metadata with copyrighted archives removed;
- exact error text and reproduction steps;
- whether the game launches with the mod disabled.

Do not upload game assets, paid mods, credentials, personal information, or
full crash reports without reviewing them for sensitive paths and identifiers.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).
