# Checker Texture Starter

This is a complete Unreal Engine 5.1.1 project for building a small,
redistributable Palworld texture mod on Apple Silicon.

The example replaces the seven known base-color textures used by the female
cloth/starter outfit with an original cyan, magenta, yellow, and black checker
pattern. It leaves the game's normal maps and material masks untouched.

No Palworld assets are included. The texture is generated by the Swift source
in `Pal/Tools/generate_texture.swift` and is covered by PalMac's MIT license.
Package and object names are compatibility information, not copied game
content.

## What the build does

`Pal/Scripts/build-mac-mod.zsh`:

1. verifies Unreal Engine 5.1 and Retoc are available;
2. generates the checker PNG if it is missing;
3. imports seven copies at the exact Unreal package paths;
4. cooks only those textures for the `Mac` target;
5. creates an intermediate legacy PAK with UnrealPak;
6. converts it to UE5.1 IoStore with Retoc;
7. verifies the IoStore container and lists its contents;
8. creates a PalMac package, ZIP archive, and SHA-256 checksum.

The legacy PAK is an intermediate. The `.pak`, `.utoc`, and `.ucas` IoStore
triplet in the final package is required by the tested native game build.

## Requirements

- Apple Silicon Mac;
- Unreal Engine 5.1.1 installed by Epic Games Launcher;
- Xcode command-line tools;
- an Apple Silicon build of [Retoc](https://github.com/trumank/retoc/releases);
- PalMac built from this repository.

Download Retoc from its official release page and verify the checksum published
with that release. Put `retoc` on your `PATH`, or set `RETOC` to its full path.
PalMac does not bundle or download Retoc.

## Build

From the repository root:

```sh
cd Examples/CheckerTexture
RETOC=/full/path/to/retoc zsh Pal/Scripts/build-mac-mod.zsh
```

If Unreal Engine is installed somewhere other than the Epic Games default:

```sh
UE_ROOT="/full/path/to/UE_5.1" \
RETOC="/full/path/to/retoc" \
zsh Pal/Scripts/build-mac-mod.zsh
```

The finished files appear under:

```text
Examples/CheckerTexture/Build/
├── PalMacCheckerTexture/
│   ├── Info.json
│   └── Paks/
│       ├── PalMacCheckerTexture_P.pak
│       ├── PalMacCheckerTexture_P.ucas
│       └── PalMacCheckerTexture_P.utoc
├── PalMacCheckerTexture.zip
└── PalMacCheckerTexture.zip.sha256
```

Validate it before installation:

```sh
swift run palmac validate Examples/CheckerTexture/Build/PalMacCheckerTexture
```

Then select the `PalMacCheckerTexture` folder in the PalMac app. Close
Palworld before installing or changing the package.

## Expected result

On the tested Palworld Mac revision, the female cloth/starter outfit displays
the high-contrast checker pattern. Other outfits are unchanged. Disabling the
package and relaunching the game restores the original appearance.

Game updates can rename assets or change which outfit uses these textures. A
successful build with no visual change usually means the cook worked but the
target path no longer matches the installed game revision.

## Make it your own

Replace `SourceArt/PalMac_Checker.png` with an original 1024×1024 PNG, keeping
the filename. Re-run the build. For a different target, edit the `ASSETS` list
in both:

- `Pal/Scripts/create_checker_textures.py`
- `Pal/Scripts/build-mac-mod.zsh`

The directory, package name, and object name must match the target exactly.
Read the [texture walkthrough](../../docs/TEXTURE_STARTER.md) before
distributing a converted mod.
